Quran data source: quran-json (Risan), which states that its Uthmani Quran text is sourced from The Noble Qur'an Encyclopedia. See project README for licensing/source details.

For the Tanzil text itself, Tanzil requires attribution, a link to tanzil.net, and verbatim use without changing the text. This project therefore downloads the quran-json dataset at build time and does not alter the Arabic text.
