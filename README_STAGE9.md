# Quran Hifz — Stage 9: Hifz + Ağıllı Təkrar

Bu mərhələdə əzbərləmə və təkrar sistemi genişləndirildi.

## Əlavələr
- Ayə üzrə öyrənmə kartı və gizlət/göstər.
- 4 qiymətləndirmə: Yenidən, Çətin, Yaxşı, Asan.
- Adaptiv interval: cavaba görə növbəti təkrar vaxtı hesablanır.
- Yeni ayələr üçün başlanğıc təkrar planı.
- Gecikmiş (due) ayələrin prioritetləşdirilməsi.
- Təkrar sessiyasında növbəti ayəyə keçid.
- Streak və sessiya statistikası.
- Ayə üzrə səviyyə, interval və növbəti təkrar məlumatı.
- Əzbərlənmiş ayə statusu yalnız uyğun nəticədən sonra yüksəldilir.
- Məlumatlar localStorage-da saxlanılır.
