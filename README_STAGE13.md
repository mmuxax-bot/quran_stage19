# Stage 13 — Gündəlik Hifz Planı və Bildirişlər

Bu mərhələ əvvəlki Stage 12 üzərində qurulub.

## Əlavələr
- Gündəlik hifz plan kartı
- Bu gün tamamlanan / qalan ayələrin göstəricisi
- Gündəlik hədəf bildirişi
- Seçilə bilən bildiriş vaxtı
- Təkrar üçün ayrıca gündəlik xatırlatma
- Bildirişləri aktiv/söndür
- Android üçün Capacitor Local Notifications inteqrasiyası
- Brauzer rejimində Notification API üçün ehtiyat yol
- Bildiriş parametrlərinin localStorage-da saxlanması

## Qeyd
APK hələ hazırlanmayıb. Android build zamanı `@capacitor/local-notifications` native modulunun sinxronlaşdırılması tələb olunacaq.
