# Quran Hifz — Stage 8: Real Qiraət Audio

Bu mərhələ Stage 7 üzərində qurulub. APK hələ hazırlanmayıb.

## Əlavə edilənlər
- Real ayə audio oynatma sistemi
- Mishary Alafasy, Abdul Basit Murattal və Mahmoud Khalil Al-Husary seçimləri
- Play / pause
- Əvvəlki və növbəti ayəyə keçərək audio davam etdirmə
- Audio progress bar və vaxt göstəricisi
- 1 / 3 / 5 dəfə təkrar
- Davamlı (loop) təkrar
- 0.75× / 1× / 1.25× sürət
- Seçilmiş qari, təkrar və sürət ayarlarının localStorage-da saxlanması
- Audio bitdikdə növbəti ayəyə avtomatik keçid
- Hifz ekranındakı "Dinlə" düyməsi də real audio sistemindən istifadə edir

## Audio mənbə
Audio URL-ləri EveryAyah formatına uyğun dinamik qurulur. Buna görə qiraəti ilk dəfə yükləmək üçün internet bağlantısı lazımdır. Quran mətni isə ayrıca lokal data paketindən istifadə edir.

## Növbəti mərhələ
Stage 9: Hifz üçün daha güclü təkrar/əzber alqoritmi, çətinlik səviyyəsi, gündəlik sessiya və avtomatik planlama.
