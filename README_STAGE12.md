# Stage 12 — Tərcümə və Quran görünüş ayarları

Bu mərhələdə Quran oxuyucusuna ayrıca Ayarlar bölməsi əlavə edildi.

## Funksiyalar
- Gündüz/gecə mövzusu Quran mətnindən ayrıca idarə olunur.
- Azərbaycan dilində tərcüməni göstər/gizlət seçimi.
- Tərcümə məlumatı JSON paketində olduqda ayənin altında göstərilir; olmayan halda saxta tərcümə yaradılmır.
- Ərəb mətn ölçüsü: 22–48px.
- Sətir aralığı: 1.4–2.5.
- Seçimlər localStorage-da saxlanılır.
- Ayarlar menyudan və başlıqdakı ⚙ düyməsindən açılır.

## Qeyd
Bu mərhələdə tərcümə interfeysi və data dəstəyi hazırdır. Faktiki Azərbaycan tərcümə korpusu ayrıca, düzgün mənbədən əlavə edilməlidir; uydurma tərcümə istifadə olunmur.

APK/Termux hələ hazırlanmayıb.
