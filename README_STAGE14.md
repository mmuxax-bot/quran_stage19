# Stage 14 — Səslə Hifz Yoxlaması

Bu mərhələdə istifadəçi seçilmiş ayəni əzbərdən səslə oxuyur və Web Speech Recognition nəticəsi ayənin ərəb mətni ilə müqayisə olunur.

## Funksiyalar
- Mikrofonla ərəb nitqinin tanınması
- Tanınan mətnin ekranda göstərilməsi
- Ərəb mətninin sadələşdirilmiş normallaşdırılması
- Mətn uyğunluğu üzrə 0–100% nəticə
- Çatışmayan/artıq sözlərin ilkin göstəricisi
- Nəticəyə əsaslanan məşq tövsiyəsi
- 75%+ nəticə fəaliyyət statistikasına yazılır
- Mikrofon icazəsi və dəstək yoxlaması

## Məhdudiyyət
Bu sistem təcvid, məxaric və səs keyfiyyətini elmi qiraət yoxlaması kimi qiymətləndirmir. O, nitqdən-mətnə çevrilən ərəb sözlərini ayə mətni ilə müqayisə edir. Daha dəqiq qiraət qiymətləndirməsi ayrıca audio/AI model inteqrasiyası tələb edir.

APK/Termux bu mərhələdə hazırlanmayıb.
